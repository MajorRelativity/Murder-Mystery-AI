## Description: 
_**A murder mystery game meant to demonstrate the potential of ChatBots in gaming**_


In concordance with 'GateHacks 2024's theme of utilizing Generative AI, this game illustrates how GenAI can turn non-playable characters (NPCs), which so frequently feel static due to a select number of preprogrammed diaglogue options, into dynamic entities that can engage in unique and entertaining dialogue with a user, thus enhancing gameplay.
